# HeyDrew Homepage Redesign — Spec (2026-09-24)

## Goal
Reimagine heydrew.com's homepage so it converts like a $100M fintech brand.

## Decisions (from the user)
- **Primary conversion:** Start the TaxLand assessment ("See what you can keep"). Secondary: book a strategy call.
- **Direction:** Premium fintech credibility (think Ramp, Mercury, Pilot) with Drew as a charming guide at key moments, not wallpaper.
- **Imagery:** 3–6 new Higgsfield renders, on-model to the Drew spec (backwards black cap, black puffer vest over white hoodie, gold watch, beaded bracelets, 3D Pixar style).
- **Deliverable:** A responsive coded HTML prototype (in this folder, published as a private link) plus a conversion-strategy doc.

## Inputs
- Brand kit: `../brand-research/HEYDREW_BRAND_KIT.md`, tokens: `../brand-research/heydrew-tokens.css`
- Assets: `../brand-research/assets/`, screenshots: `../brand-research/screens/`
- Voice: `../HeyDrew_BrandVoice_v1.docx`

## Constraints
- Keep brand equity: DM Sans, navy #1E285F, money green CTA, the HEY DREW! logo, and Drew. Elevate them; don't replace them.
- Compliance: savings figures must be framed as illustrative, with a disclaimer. Never promise results.
- No fabricated testimonials or logos. Use the real testimonials from the current site; mark any placeholder metrics clearly.
- CTAs go to https://taxland.heydrew.com/ (assessment) and the call-booking path.

## Team & flow
1. Research (parallel): CRO specialist · Senior web / UI-UX designer · CMO + senior brand strategist
2. Blueprint: CMO merges everything into a section-by-section plan
3. Imagery: graphic designer (Higgsfield), running in parallel
4. Build: senior web designer (impeccable + taste skills)
5. Critique: UI/UX, CRO and brand review → fixes → publish

## Output files
- `research/` — agent research notes
- `BLUEPRINT.md` — the section-by-section plan
- `CONVERSION_STRATEGY.md` — why each section exists
- `site/index.html` + `site/img/` — the prototype
